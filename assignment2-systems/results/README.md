# End-to-End Benchmark Results

The files in `end_to_end/` are raw benchmark outputs generated by
`cs336_systems.run_benchmark_suite`. The figures in `figures/` are generated
from those JSON files by `cs336_systems.plot_benchmark_results`.

## MPS Baseline

- Machine: MacBook Pro (`Mac17,2`)
- Chip: Apple M5, 10-core GPU
- Memory: 24 GB unified memory
- GPU API: Metal 4 through the PyTorch MPS backend
- Operating system: macOS 26.5.2
- PyTorch: 2.11.0
- Model: `small`, 128,625,408 parameters
- Workload: batch size 4, context length 512, FP32
- Timing: 5 warmup steps, 10 measured steps, device synchronization at each
  timing boundary

Generate the raw results with:

```bash
uv run python -m cs336_systems.run_benchmark_suite \
  --device mps \
  --model-sizes small \
  --modes forward forward_backward full \
  --batch-size 4 \
  --context-length 512 \
  --warmup-steps 5 \
  --measurement-steps 10
```

Regenerate the figure with:

```bash
uv run python -m cs336_systems.plot_benchmark_results
```

These MPS measurements are a local development baseline, not the CUDA results
required for the assignment write-up.
